# Capstone Project

This repository contains my frontend capstone project completed as part of my internship.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Git
- GitHub

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/tushar22199/capstone-project.git
   cd capstone-project
   ```
2. Install [Node.js](https://nodejs.org/) (LTS recommended) for local development.
3. Open the project folder in [Cursor](https://cursor.com/) to use AI-assisted development.
